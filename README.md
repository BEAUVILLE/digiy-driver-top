# DIGIY DRIVER — Tableau de bord Chauffeur

Client web pour chauffeurs DIGIY DRIVER, thème noir & or.

- Connexion simple par téléphone + PIN (démo)
- Lecture des courses dans `rides/{rideId}` sur Firebase Realtime Database
- Statuts supportés : `pending`, `searching`, `accepted`, `picking_up`, `client_on_board`, `arrived`, `completed`
- Attribution chauffeur via `driverId` / `driverName` / `driverPhone`

Déploiement conseillé : GitHub Pages ou hébergement statique (Hostinger, Netlify, etc.).
